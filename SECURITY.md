# Security Policy

## Supported versions

The current `main` branch is supported. Earlier versions are not currently
maintained separately.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public GitHub issue.

Report them privately to [security@thenational.academy](mailto:security@thenational.academy), or use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability).

Please follow Oak National Academy's [security disclosure policy](https://www.thenational.academy/legal/security-disclosure-policy/).
